Inside

Everything a desktop does, without a display server.

The graphics stack is the terminal itself. That keeps the system small and every app usable over ssh.

console

kmscon

The login console in truecolor with mouse support and good fonts, in place of the kernel's plain text console.

desktop

tetron-wm

Floating windows, a taskbar, a launcher, a file manager, themes, and a Store with 600+ terminal apps. Detach and reattach like tmux.

network

tetron

A peer-to-peer mesh VPN: your machines reach each other directly and encrypted, wherever they are, with no account and no central server.

web

tetron-browser

Chromium drawn in text: JavaScript, logins and images in the terminal. The desktop opens web pages in it.

apps

App collections

The Desktop comes with the essentials and recommended collections: a file manager, editors, media players, system monitors, disk and network tools.

hardware

Laptop ready

Wi-Fi, sound (PipeWire), Bluetooth, backlight and battery, CPU microcode, and all firmware on the -fw image.

tetron mesh VPN

The core: every machine you own, one private network.

tetron is the heart of TetronOS. Every edition installs it, and it connects your laptop, servers, home machines and phone into one encrypted peer-to-peer network, wherever they are: at home, at work, behind NAT, on mobile data.

invite

Invite only

Create a network, mint an invite key, join from the other machine. Invites are single-use and expire after 7 days by default. No account, no sign-up.

direct

Direct and encrypted

Peers connect straight to each other over QUIC, punching through NAT with iroh. A relay only helps them find each other, or carries encrypted traffic when no direct path exists.

address

Stable addresses

Each machine gets a stable IPv4 and IPv6 address in every network, derived from its identity. ssh, file shares, web apps: any TCP or UDP program works over it.

separate

Many networks, kept apart

Each network gets its own interface and subnet, like a second network card. Co-coordinators keep a network running when one machine is off; Tor and self-hosted relays are options.

  • Built into the desktop. The tetron-wm tray shows your peers and how they connect, with one switch for all of tetron and Resume or Standby per network; tetron-tui is the full dashboard in a terminal.
  • Ready at first boot. TetronOS makes the first user the tetron operator, and on first boot joins a network when an invite was left for it (/etc/tetron/pending-invite).

Yours

You control the device, not the vendor.

TetronOS is Debian plus a handful of small, readable packages. Nothing is hidden in an image.

  • Plain packages. Every TetronOS part is a .deb in a signed apt repository; apt upgrade updates the system and the suite together.
  • Run your own build. Clone a project, change it (by hand or with an AI assistant), build it and run it in place of the packaged one; the package stays installed and switching back is one command. tetron-wm supports this today.
  • Open source. The image recipe, the packages and every suite project are public on GitHub. Build the ISO yourself with one make.
  • Your network. tetron connects your machines peer to peer. No account, no cloud service in the middle.

Get it

Three ways, today.

installer

The suite on your system

On Debian, Ubuntu, other Linux or macOS: the installer asks for tetron or tetron-wm and sets it up.

apt

The apt repository

Debian 12+ and Ubuntu 22.04+, amd64 and arm64: every suite and TetronOS package, upgraded by apt upgrade. tetronos apt.

make iso

Build the ISO

Clone tetron-os, then make vm-create once and make iso EDITION=desktop. Builds in a Debian 13 VM, or a container with RUNNER=docker.

$curl -fsSL https://tetronos.github.io/install.sh | bash

Read before you run: install.sh
